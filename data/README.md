# Raw source storage

`data/raw/` holds large third-party downloads used to build dataset releases.
It is **git-ignored** and must not be committed.

For the Delhi pilot, fetch the raw sources with:

```bash
.venv/bin/pip install -r backend/requirements-data.txt
.venv/bin/python backend/scripts/fetch_delhi_sources.py
```

This writes about 140 MB into `data/raw/delhi/`:

| File | Source | Licence |
| --- | --- | --- |
| `delhi_boundary_osm.json` | OpenStreetMap relation 1942586 via Overpass | ODbL 1.0 |
| `facilities_osm.json` | OpenStreetMap healthcare features via Overpass | ODbL 1.0 |
| `roads_body.json` | OpenStreetMap drivable ways via Overpass | ODbL 1.0 |
| `Delhi_Wards.geojson` | DataMeet Municipal_Spatial_Data | CC BY-SA 2.5 IN |
| `ward_census.xlsx` | Census of India 2011 ward PCA (NADA catalog 42560) | Government of India public data |
| `delhi_district_population_census2011.pdf` | Directorate of Economics & Statistics, GNCT Delhi | Government of NCT of Delhi public data |
| `SOURCES.json` | Retrieval timestamps and SHA-256 checksums | Generated by this project |

The normalized, committed release lives in `backend/app/data/delhi/`. Raw files
are retained only so the release can be rebuilt and audited; they are never
served by the API.
